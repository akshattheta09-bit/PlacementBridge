# Threat model and pilot gates
Assets: identity, institutional announcements and audit history; future personal and confidential records. Threats include forged roles, direct action calls, cross-institution IDs, self-approval, replay/races, injected content, stolen sessions, misleading synthetic records and insider access. Controls: database-derived roles and active status, default denial, institution filters, independent approval, transactional conditional transitions and audits, bounded validation and React text encoding. Demo credentials and seed data must never be enabled in pilot or production. No real sensitive content or uploads are supported.

Open before pilot: institution-approved OIDC/SSO and privileged MFA; session revocation and rate limits; department/audience enforcement; CSRF and security-header review; independently protected audit retention; monitoring, backups and recovery; accessibility and penetration testing; legal/privacy and retention review; grievance assignment and encryption design; approved institutional governance. Existing controls have not received an independent security review.
